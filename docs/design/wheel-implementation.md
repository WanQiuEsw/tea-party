# 奶油玻璃转盘

采用已选的玻璃边框与简洁分区方向，使用 CSS 和 Canvas 实现，保持动态奖品与现有服务器抽奖规则。

- 奶油、草莓粉、浅紫和桃色分区；王者与钻石保留浅金、冰蓝区分。
- 粉色玻璃双层外圈、固定指针、25% 直径的中心按钮，支持键盘与触摸。
- 按显示尺寸调整文字大小、截短长名称并修正左半盘文字朝向；过窄分区以小标记展示，完整名称与概率可在现有概率面板查看。
- 扇区角度继续对应真实概率，服务器开奖与最终指针位置保持一致。
- 无新增运行依赖与大图下载。

验证：常规 Node 测试、完整玩法 tests/game-flow.cjs，以及独立转盘 tests/wheel-flow.cjs。转盘测试覆盖 320/390/768/1280 像素、高分辨率屏幕、按钮尺寸、窗口缩放、空清单、单奖品、密集长名称、键盘开奖与指针对齐。

运行浏览器测试需要本机 Playwright 和 Chrome，可使用 NODE_PATH 指向已有依赖；可设置 TEA_BROWSER=msedge 使用 Edge。TEA_SCREENSHOT 可指定截图前缀。
