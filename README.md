# 一口好运 · 奶茶随机转盘

一个零依赖的奶茶随机转盘：登录后抽奶茶，管理员可在后台维护饮品清单并查看抽奖记录。

## 功能

- **随机转盘**：每款奶茶对应一个扇区，抽奖结果按价格加权计算。
- **刮刮乐**：保留经典款，新增幸运号码（同号中奖）、一字定奶茶（按字对应饮品）；支持手指、鼠标刮开和按钮直接揭晓。
- **幸运拉霸**：点击摇杆或按钮，三个转轮出现相同饮品即中奖；手机可主动开启摇一摇，不支持或拒绝权限时仍可点击。
- **共用概率**：所有玩法空奖 20%、再来一次 3%、饮品 77%。饮品权重 = `1 / 参考价`，越贵越稀有；调整价格后概率自动刷新，完整概率可在页面查看。再来一次不写入饮品记录。
- **登录使用**：打开页面默认以 `user` 自动进入，无需输入账号密码；右上角「切换账号」可登录 `ping` 或管理员账号。
- **管理员后台**：新增饮品、修改参考价、删除饮品，查看所有用户的抽奖记录。
- **SQLite 存储**：饮品与抽奖记录保存在 `tea.db`，使用 Node 内置 `node:sqlite`，无需安装任何依赖。
- **手机适配**：手机端单列布局，表格可横向滚动，触控按钮不小于 44px。

## 运行

需要 **Node.js 24+**（内置 `node:sqlite`）。

```bash
node server.js
```

打开 <http://localhost:3000>。

| 角色     | 账号    | 密码       |
| -------- | ------- | ---------- |
| 普通用户 | `user`  | `123456`   |
| 普通用户 | `ping`  | `123456`   |
| 管理员   | `admin` | `admin123` |

打开页面会自动以 `user` 进入；需要 `ping` 或管理员时，点右上角「切换账号」。

管理员登录后，页面下方会出现「管理饮品清单」与「用户抽奖记录」两个区域。

## 说明

- 首次启动自动创建 `tea.db` 并写入 23 款奶茶；清空清单后重启不会自动恢复。
- 会话保存在内存中，重启服务后默认 `user` 会自动重新进入；`ping` 与管理员需重新登录。
- `index.html` 在启动时读入内存，修改页面后需重启服务。
- 换端口启动：`PORT=3001 node server.js`。
- 手机体感需要浏览器支持及安全上下文（HTTPS 或本机 localhost）；体感强弱不影响中奖概率。

## 验证

`node --test tests/game-rules.test.cjs`：验证概率、10 万次抽样、卡面与结果一致、单饮品及空清单。

已安装 Playwright 与 Chrome 的环境可运行 `node tests/game-flow.cjs`（可用 `NODE_PATH` 指向现有 Playwright 包，`TEA_BROWSER=msedge` 切换 Edge）。流程测试使用临时目录与独立数据库，不改动现有 `tea.db`；覆盖中奖、空奖、再来一次、实际刮开、摇杆/键盘/模拟体感、重复点击、记录和手机布局。手机物理传感器需真机验收。
