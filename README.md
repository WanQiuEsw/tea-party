# 随心选 · 随机选择器

吃什么、喝什么、去哪玩？填好选项，交给随心选随机决定。无需注册，支持手机和电脑使用。

## 核心功能

- **自定义选项**：通过弹窗添加或编辑，每行一个选项，重复项自动合并。
- **奶茶选择**：按品牌挑选饮品，移除不想喝的选项，保存自己的清单。
- **七种玩法**：转盘、刮刮乐、幸运号码、扭蛋、幸运摇一摇、盲盒、金光翻牌，全部直接展示，也可随机选择玩法；支持完整动画和快速揭晓。
- **结果留存**：自动保存清单和最近 50 次结果，支持回看、复制和分享。个人选项及结果保存在当前浏览器，不上传服务器。

清单内每个选项机会相同。转盘最多支持 24 个选项，更多选项可使用其他玩法。

## 本地启动

安装 **Node.js 24 或以上版本**，在项目目录运行，无需安装额外依赖：

```sh
node server.js
```

浏览器打开 [http://localhost:3000](http://localhost:3000)。更新代码后需重启服务。

## 怎么使用

1. **准备选项**：选择「自己填选项」，点击「添加选项」，在弹窗中每行填写一个选项并保存；或切换到「选奶茶」，选择店铺和饮品。
2. **选择玩法**：点击任意玩法，或点击「随机选择玩法」，按喜好选择完整动画或快速揭晓。
3. **揭晓结果**：点击开始或操作对应玩法，即可获得随机结果，并可回看、复制或分享。

清理浏览器数据或更换设备后，本地清单和记录不会自动恢复。

## 管理员

右上角「管理员入口」登录，默认账号 `admin`，密码 `admin123`。支持公共饮品清单的搜索、增删改、批量删除、CSV 导入导出，以及匿名选择次数统计。
